# 0050. A worktree folder the assistant makes is named after its branch

Date: 2026-09-27
Status: accepted 2026-09-27

## Context

FlatCheck task branches live in worktrees (ADR 0044), and on 2026-09-27 none of the four
worktree folders of `photo` said which task it held: three generated by the desktop app, and
`share-skills` made by hand. The owner reviews a task's diff in its worktree before the commit,
and asked, in chat, that the folder be named after the branch without `claude/`, recorded in
the kit and in FlatCheck.

## Decision

A worktree the assistant makes for a FlatCheck task is created with its branch in one command,
`git worktree add .claude/worktrees/<Task-name> -b claude/<Task-name> main`, from `FlatCheck/`
(or from the kit's folder, for a change that spans both, as ADR 0044 says). A worktree the
desktop app opened keeps its generated folder and has its branch renamed. The reasoning and
the rejected alternatives are the kit's ADR 0019, not repeated here.

## Consequences

CLAUDE.md states the command under Workflow. `git worktree list` and the file explorer show the
same name for the folder and the branch; the existing worktrees keep their names.
