## Assumptions (say so at review if one is wrong)

- CR-011: "no size" is what `GetInt` gives -1 for: the card missing, or its value not a whole
  number. The refusal comes after the same-file check (R-019) and before the size comparison;
  a dry run is refused too. A file with `NAXIS1 = 0` is not this case.
- CR-012: the fit and `WindowFit`'s arithmetic are copied from AstroDarkroom (its
  `ScreenArea.cs`, `WindowFit.Top`, ADR 0007), into `src/CopyWcs.Wpf/Presentation/` (they place a
  window, nothing about the copy). The window stays resizable: only its opening height and its
  minimum are capped to the work area, not its maximum. The new minimum height is measured in
  the task (about 680 by the probe's figures: four card rows instead of 29 px).
- CR-017: the window follows R-033 (warnings, then the refusal), not the other way; no ADR, the
  requirement already says it.
- CR-018: `File.Replace(temp, target, null, ignoreMetadataErrors: true)` when the target
  exists (so a drive with no permissions to carry over, FAT or a share, does not fail the copy),
  `File.Move` when it does not. A target that vanishes between the two is a write error, the
  temporary file deleted. Links: recorded as measured (hard link broken, as before; symbolic
  link not measurable here). The two limits the entry's note added (room for both files, a
  folder where a file may be changed but not created) stay, as the nature of a write through a
  temporary file.
